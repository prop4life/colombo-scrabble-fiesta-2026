# Colombo Scrabble Fiesta 2026

Live results website for the Colombo Scrabble Fiesta, 17–18 October 2026 at Colombo City Center, organized by Sri Lanka Scrabble Academy.

## Categories
- Under 13 — 6 rounds — 17 October 2026
- Championship — 16 rounds — 17–18 October 2026
- Plate / Newbies Category — 7 rounds — 18 October 2026

## Publishing
The live site is built on the `production` branch. Configure GitHub Pages to deploy from `production` / `(root)`.

The private tournament update page is `admin.html`. It supports pairings first, standings later, corrected standings overwrite, automatic player-stat rebuilds, official cumulative TSH spreads, clickable player profiles, head-to-head records, and optional player photos.
